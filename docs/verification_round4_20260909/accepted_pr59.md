# PR59：紧致管邻域与真实熵率接口的限定接受

状态：**ACCEPTED_SCOPED**。作者冻结头 `892a121a6e26fcf638c75de917e50a4503b5675e` 的全部 14 个文件以 `0a396f65e4daa9407bb4ed6295f703d4d2e0dfe1` 合入。该作者头在两次独立审查之间没有改动。

## 接受的五个单元

1. **预先指定紧致区间上的真实熵率凹性。** 固定 `beta>0`、`0<mu<1`、实半周期奇的非零 `g in A_beta`、满足 `g_hat(k)!=0` 的奇数 k，以及常数中心弦 `mu+t g` 严格合法的任意预先指定紧致区间 `[-T,T]`。存在 `rho>0`，使每个实半周期偶、均值 mu、`||c-mu||_beta<rho` 的中心 c 都满足：`h(c+t g)+(2/3)|g_hat(k)|^4 t^4` 在整个 `[-T,T]` 上凹。因此真实熵率在所有非平凡子弦上严格凹。rho 是存在性半径，没有给出数值。
2. **完整的 RPF 二阶恒等式。** 对满足简单隔离特征值与谱隙假设的严格正、归一化 Holder g-function 族，令 `phi=log G`、`psi=dot phi`、`xi=ddot phi`、`B=-L phi`、`u=R B`，R 为中心化预解算子。接受 `h''=nu(ddot B)+nu(xi u)+2nu(psi R dot B)+2nu(psi R(psi u))-nu(psi^2 u)`。局部 Fisher、加速度和响应项全部保留；该恒等式不是一般曲率符号定理。
3. **有限状态到真实熵率曲率的误差接口。** 在严格指数局域符号及紧致严格区间上，有限未来条件概率及其前两阶参数导数以指数误差收敛，并可经统一谱轮廓、特征测度与预解算子控制得到体积无关的曲率余项。此处只接受解析存在性接口。未来数值证书仍须给出具体有向区间计算与几何尾界；本稿没有执行此类证书，也没有提供具体尾界常数。
4. **平衡两层混合的占据态互信息障碍。** 有限窗口的平衡输出协方差为 `[[M,u K_g],[u K_g,M]]`，两侧占据态边缘固定为核 M 的 DPP。中点熵差等于输出互信息与占据态熵增之和。在严格指数局域假设下，按每个双坐标 cell 归一化的真实率也满足相应恒等式；输出互信息在零点为 `O(u^4)`，因此 `i_out''(0)=0`、`e_occ''(0)=-2h''(t_*)`。`E_occ>=0` 仍未证明；量子 von Neumann 熵不等式不能替代这里需要的占据态 Shannon 不等式。
5. **均值 1/3 的非恒定中心族。** 取 `g(theta)=cos(2 pi theta)/8`、`T=2`、`c_epsilon(theta)=1/3+epsilon cos(4 pi theta)`。常数中心弦位于 `[1/12,7/12]`，四次修正系数为 `1/98304`。对每个固定 beta，`0<|epsilon|<min{rho(beta)exp(-2beta),1/24}` 是非空参数区间，整条路径没有常数符号。这里没有把存在性 rho 换成显式数值，也没有宣称覆盖 PR39 的固定均值 1/2 区间。

## 证明依赖与审查证据
