## Positive findings

The production route is aligned with the request's physical `t` convention. The request defines the scaled event matrix and first off-diagonal derivative in [REQUEST.md](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/inputs/REQUEST.md#L15); the implementation README repeats that the first off-diagonal derivative is 2 and the second product derivative retains the factor in [implementation/README.md](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/README.md#L7).

Complete-event retention is present at the code and artifact level. The code emits histograms keyed by `N` with `count`, `sum_Nprime`, `sum_Nsecond`, and `sum_NprimeSquared` in [independent_pr77_checker.py](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/independent_pr77_checker.py#L712) through [independent_pr77_checker.py](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/independent_pr77_checker.py#L756). The histogram schema matches the request's reconstruction requirement and the implementation README's reconstruction formula in [implementation/README.md](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/README.md#L13).

Fisher and acceleration are not collapsed or silently discarded. They are accumulated as separate directed intervals in [independent_pr77_checker.py](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/independent_pr77_checker.py#L429) through [independent_pr77_checker.py](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/independent_pr77_checker.py#L453), and the finite outputs expose both fields plus the log32 normalization note in [t1_n18_finite.json](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/outputs/run01/D/t1_n18_finite.json#L16) through [t1_n18_finite.json](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/outputs/run01/D/t1_n18_finite.json#L46).

The true-rate curvature tail addition at [independent_pr77_checker.py](https://github.com/randomcat4/dpp-entropy-tools/blob/1d805e094a0faf0018127ee832f5e1ac74996b41/research/C2/pr77_fixed52/implementation/independent_pr77_checker.py#L516) uses the positive tail radius symmetrically around the finite interval.
