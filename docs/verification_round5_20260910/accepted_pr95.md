## 接受的固定对象结论

对 PR58 Section 3 精确定义的稠密相关 `3+3` 实核族

`K(t)=[[A,tUV^T],[tVU^T,C]]`，

两侧边缘均严格相关，`U,V` 均为满列秩二，全部九个交叉项非零。以六个实际观察坐标的 64 个完整事件概率定义 Shannon 熵。令

`s_*=t_*^2`，

则正端点由 full event 的二次因子唯一简单零点给出，并满足

`0.999911107034345070 < s_* < 0.999911107034345071`，

`0.999955552529383713 < t_* < 0.999955552529383714`。

该路径的整个最大合法闭区间正是 `[-t_*,t_*]`；在其内部

`H''(t) <= -t^2/2`，

并且边界连续延拓后 `H(t)+t^4/24` 在全闭区间凹。零点的二阶曲率为零，严格性由真实四阶损失给出。证明使用完整事件分解

`q_s=1-sa+s^2b`

与完整 Fisher、加速度及混合项；三个连续区间由二次式端点/顶点的精确极值覆盖，不是网格外推。末端稀有 full event 没有被丢弃，其 `1/q` Fisher 极点与对数加速度项一起得到严格正下界。

## 接受的邻域与移动端点结论

作者的系数空间半径 `10^-6` 稳健性界成立；显式矩阵/因子逐项半径 `10^-12` 的盒被严格映入该系数邻域。因此盒中每条路径都在它**自己的**最大合法区间上满足上述凹性和严格性，端点允许随参数移动，不能误写成固定参考子弦。

新增解析附录进一步证明：对任意固定的有限 `m,n>=3`，在满足两侧严格相关、交叉块秩二且全部交叉项非零的简单端点对象附近，存在相对开邻域，使每个成员在自己的最大合法弦上有

`H(t)+t^4/48`

凹。简单消失原子贡献给出 `1/delta` 量级的 Fisher 主项，而其对数加速度仅为对数量级；其余原子在移去端点薄层后由紧致性统一控制。该结构性结论给出相对开且稠密的相关秩二类别，但半径是存在性的，且依赖固定维数与参考对象。
