# T2: finite-block entropy-gap transfer

Status: RUNNING. One bounded tool objective, not a global-concavity claim.

For a finite Hermitian positive contraction K, let P_K be the DPP characterized by P_K(S subset X)=det K[S,S]. Its full-subset Shannon entropy H(K) uses natural logarithms and 0 log 0=0. A partition of the coordinate set defines the block pinching B. The tool must compare H(K) with the sum of the block entropies, then control the signed Jensen gap of two kernels and their affine midpoint. Spectral entropy tr h(K) is a distinct quantity, never an alternative definition of H(K).

Success means a frozen finite-dimensional theorem, complete derivation, reusable evaluation interface, one parameterized application and one explicit limitation. The evaluation should avoid enumerating all subsets of the full system. Any numerical output is only a probe unless exact arithmetic or directed enclosures establish its claims.

Scope excludes a stationary-rate theorem, scalarization of block processes, unproved complex-to-real transfer, Hessian control from an entropy-value bound, and large scans. Repeated blocks may test accounting but are not a new stationary construction.
