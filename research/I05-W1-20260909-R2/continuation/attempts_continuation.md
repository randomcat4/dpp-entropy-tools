# attempts_continuation.md

任务：I05-W1-20260909-R2 continuation。总体状态 `PARTIAL`。本文件只记录本轮在已有条件 Schur 与 `m x 2` 定理之后的新路线；不重复上一轮已经完成或已经严格否定的路线。

## 1. 条件 Schur + 对角锚点：成功，但有结构边界

精确桥接仍是

\[
p_{K(t)}(S,T)=p_A(S)p_{C-t^2M_S}(T),
\qquad M_S=B^T(A-E_{S^c})^{-1}B.
\]

本轮没有要求 `rank(M_S)<=2` 后直接调用未知的一般 rank-two 直线凹性，而是检验每条条件线是否落入另一独立团队已证明的“通过严格对角核的整条合法直线”范围。

成功得到两种可检查情形：

1. 所有耦合坐标组成 `C` 的坐标约化子空间，且该活动主块为对角核；此时 `|J|` 和 `rank(B)` 都不限。
2. 对每个左配置 `S`，直线 `C-sM_S` 存在某个严格对角锚点 `C-sigma_S M_S`。

第一种给出两侧块都大于二、右奇异平面稠密使用三个坐标的 rank-two 全弦定理。边界也很明确：若活动子空间本身相关，条件线一般不经过任何对角核，不能只靠平移参数继续使用该定理。

## 2. rank-two 外幂/混合判别式 + 经典 Markov 交织：形成新关键引理，尚未全闭合

对 `rank(B)=2`，精确似然比只包含外幂次数 0、1、2：

\[
r_s=1-s\operatorname{tr}(G_AG_C)+s^2d_Ad_C.
\]

这提示寻找保持 `p_C` 的 Markov 算子，使一次特征 `G_C` 按 `theta` 衰减、二次外幂 `d_C` 按 `theta^2` 衰减。若存在，则 `(Id tensor T_theta)P_s=P_{theta s}` 逐项精确成立。

对角 `C` 时，该算子正是逐坐标独立刷新：中心化 Bernoulli 分数是一阶 Walsh 特征，二维混合判别式是互异坐标二次 Walsh 特征。这条路线成功解释了为什么独立刷新可以越过交叉秩一，以及为什么整块刷新在 `Q` 项处失败。

一般相关 `C` 时，剩余对象不是一个含糊的“信息收缩常数”，而是有限配置空间上的正生成元：

\[
LG_C=-G_C,\qquad Ld_C=-2d_C.
\]

可逆生成元用非负导通量表示后是有理线性可行性问题。即使可行，数据处理只给互信息单调；真实 `t`-凹性还要求

\[
2\mathcal I''+\mathcal I'\ge0,
\]

其中 `I''` 含完整 Fisher 项。该路线因此提供了直接可由服务器检验的新引理，而没有把单调性误写成曲率。

## 3. 准自由/fermionic Gaussian 衰减 + 占据测量：精确桥接，经典下降失败

在单粒子协方差层，局部规范不变准自由衰减可以固定相关边际并缩放跨块协方差；量子相对熵受数据处理控制。这看似能产生目标径向族。

关键问题是：固定观测基中的占据配置分布是否也由一个与输入无关的经典随机核演化？本轮用两个严格两模核给出否定答案。`K_+` 与 `K_-` 只有非对角元符号不同，完整配置分布相同；经过同一个相关固定点衰减后，满事件概率分别为 `91/400` 和 `99/400`。所以占据测量不是该量子通道的充分统计量。

该失败不否认量子数据处理，也不等同于上一轮的整块刷新障碍。仍可能存在“量子相对熵减去测量损失”的可控曲率，但目前没有闭合不等式。

## 4. 两条没有形成定理的辅助尝试

### 4.1 把任意 rank-two 方向拆成两个 rank-one 方向

写 `B=u_1v_1^T+u_2v_2^T` 后引入两个缩放参数。沿坐标轴可调用 rank-one 结果，但混合二阶导数含真正的二阶外幂系数和对数权重；分别凹不能推出对角径向线凹。该方法只是把 `Q` 障碍改写成混合 Hessian，没有新符号。

### 4.2 用辅助两模边界集中模拟非坐标奇异平面

试图把一般二维子空间嵌入更大坐标系，再让额外模式趋于确定以恢复“两个坐标支撑”。严格合法区间随边界参数收缩，稀有邻接事件的完整 Fisher 项同时发散；没有得到可交换的统一极限。有限负样本不能替代这一缺口。
