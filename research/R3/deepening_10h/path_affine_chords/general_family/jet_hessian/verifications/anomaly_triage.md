## 2. 与作者不同的稳定递推

作者使用未归一化 Z、T=Σw log w，最后 H=logZ-T/Z。本验证改用
“最后连续选中段”的互斥混合熵，且用 LDL 枢轴的对数累加计算每个
区间的 log determinant，从不形成巨大 T 或其商的倒数三次幂。

在长度 m 的前缀上，类别分别为：最后坐标不选（前缀 m-1），以及最后
连续选中段 [a,m-1]（其前缀长 max(0,a-1)）。这些类别穷尽且互斥。
设该类别的前缀为 r，段权为 κ（不选类别κ=1），其对数权
`ell=logZ_r+logκ`，归一化概率 `q=exp(ell-logZ_m)`。段选定后余下配置
正是前缀 L-ensemble，所以

`H_m=Σ_categories q (H_r-logq)`。

logZ_m 用 log-sum-exp。由路径 L 主子式的连续段乘积分解，这恰为全
配置熵，不是把 det K_S 当作事件概率。每个运算用 (常数项,t系数,t²
系数) 的截断多项式，商按系数递推；最后 H''=2×t²系数。

独立小维闸门：冻结一个 n=6 的有理路径族，rank2，一共64个事件。
通过包含主子式的 direct-Möbius 反演获得精确事件的二次系数；将其
直接计算的 H,H',H'' 与稳定DP比较，80位差依次为
`1e-79, 4.3e-81, 9e-82`。所有精确概率及约分分母保存在结果中。
这验证实现的小维事件语义，不把有限检查提升为一般定理认证。

## 4. 可行性、仿射性、秩与非退化

R 为固定单位下双对角、次对角 -beta，U=R^-1。因此
`K(t)=I-U diag(tau+t delta) U^T` 精确 K-affine，
`D=-U diag(delta)U^T`。可逆合同保持秩及惯性，故 D 是 PSD rank2。
中心严格核秩93，与 D 不成比例，非 thinning。beta 全非零，路径不解耦。

对 t=-1/10,0,1/10，用全部精确十进制有理参数形成三对角
`P(t)=R^T diag(1/(tau+t delta))R`，分别验证 P-4I 与50I-P 的所有93个
LDL枢轴严格正；没有以浮点谱数代替有理判定。端点有
`(1/50)I<S=P^-1<(1/4)I`，S(t) 仿射，故此界覆盖整个|t|≤1/10。
于是整个区间严格 DPP 谱裕量至少1/50，全部五条弦均严格可行。
程序记录的枢轴最小值浮点展示仅作摘要，证书由有理运算重新生成。

## 5. 定量根因：jinv 的中间下溢

读取的作者 jet_hessian.py 第74行计算

```
inv = 1.0 / Z
inverse_second = 2.0 * Z1 * Z1 * inv**3 - Z2 * inv * inv
```

异常样本 Z≈1.3414055409181304e118，因此

```
inv        ≈ 7.454867074095623e-119
inv**3 真值≈ 4.1430455889123942e-355
inv**3 float = 0.0
```

虽然正确的整个项 `2Z1²/Z³` 可表示，其最右因子提前下溢，乘法无法恢复。
作者第212行将该错误逆元与 T 相乘；这使 H'' 比真值额外增加

`E=2 (T/Z)(Z1/Z)²`。

| 量 | 数值 |
|---|---:|
| 作者 float H'' | 184.7448188718266 |
| 独立稳定 H'' | -0.00702491893361558 |
| 观测上移 | 184.75184379076020 |
| 公式预测 E | 184.75184379076026 |
| 观测减预测 | -5.684341886080802e-14 |
| 从作者值扣除 E | -0.007024918933666413 |

根因误差解释到双精度量级。最终 `logZ≈271.999` 与 `T/Z≈249.977` 的
相减只有温和消去，不会凭空产生约185的二阶曲率。
不使用作者 Z,Z1,T 数值，完全从独立DP的 logZ、H、(logZ)' 重算
`2(logZ-H)((logZ)')²`，也得到
`184.751843790760182116538267198956764837...`。

建议作者另行修复：逆元二阶改成
`inv*(2*(Z1/Z)**2-Z2/Z)`，或直接采用归一化对数/商递推；应增加
`Z≈1e118` 的回归用例。验证者按权限未修改作者实现。此代数改写只消除
当前中间下溢，不保证未归一化DP在任意更大尺度都稳定。
