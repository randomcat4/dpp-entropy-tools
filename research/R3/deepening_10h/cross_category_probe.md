# 冻结后跨范畴再编码探针

本页只做表示迁移，不证明、不证伪。`APPLIED-TO-TARGET-BEFORE` 是待文献
审计的初始标签，不是新颖性结论。排序先按忠实性，再按未见直接应用项。

## 0D-1：信息几何 / 概率单纯形

1. 目标范畴：有限概率单纯形上的熵、KL 散度与信息投影。
2. 编码：严格 DPP 核 `K` 映到其 `2^n` 维精确事件概率向量 `p_K`；
   `K` 的仿射弦映到概率单纯形中的一条非仿射代数曲线；目标是该曲线
   上 Shannon 熵的中点不等式。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：行列式概率模型嵌入上的 Shannon 熵拉回是否凹。
5. 原生机械：KL/Bregman 几何（UNKNOWN）；Fisher 度量（UNKNOWN）；
   信息投影（NO）；互信息链式分解（YES）；数据处理不等式（UNKNOWN）。
6. 两项机械的标准假设：KL 二阶结构要求严格正概率，当前严格核满足；
   信息投影的仿射/指数平坦性最可能失败，因为 `K -> p_K` 非线性。

## 0D-2：自由费米高斯态

1. 目标范畴：有限模规范不变准自由费米态及占据数测量。
2. 编码：`K` 映到一体相关矩阵为 `K` 的准自由费米态；精确 DPP 事件律
   是在固定模式基上测量占据数得到的经典分布；目标是测量熵对一体相关
   矩阵仿射插值的凹性。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：准自由费米态固定 Fock 基测量熵的相关矩阵凹性。
5. 原生机械：准自由态相对熵（UNKNOWN）；费米高斯信道（NO）；
   pinching/测量熵（UNKNOWN）；Majorana 协方差标准形（UNKNOWN）；
   强次可加与恢复映射（NO）。
6. 两项机械的标准假设：准自由态公式要求合法相关矩阵 `0<=K<=I`，当前
   满足；量子通道对相关矩阵插值的封闭性最可能失败，因为一般态混合不
   等于相关矩阵对应的准自由态。

## 0D-3：实稳定多项式 / 强 Rayleigh 测度

1. 目标范畴：多仿射实稳定概率生成多项式。
2. 编码：`K` 映到 `g_K(z)=det(I-K+K diag(z))`；其系数是精确事件概率；
   目标是矩阵仿射插值诱导的稳定多项式系数熵中点不等式。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：行列式实稳定多项式族的系数 Shannon 熵凹性。
5. 原生机械：稳定性保持算子（UNKNOWN）；proper position（NO）；
   Lorentzian 多项式（UNKNOWN）；容量与系数界（NO）；外场与截断（YES）。
6. 两项机械的标准假设：稳定性保持要求线性算子符号满足稳定性判据，
   当前矩阵弦诱导的系数变换是否线性最可能失败；容量理论的非负系数和
   稳定性最可能成立。

## 0D-4：外代数 / Plücker 坐标

1. 目标范畴：Grassmann 外代数中的主子式坐标及平方体积测度。
2. 编码：经 `L`-ensemble 表示后，事件权重 `det L_S` 编为 Gram 外积的
   平方体积；归一化后得到各坐标子空间体积权重的熵。
3. 忠实性：`EQUIVALENT`（限严格核，经 `L=K(I-K)^-1`）。
4. 原生名称：Gram 主子式体积权重的归一化熵在非线性矩阵插值下的曲率。
5. 原生机械：Cauchy–Binet（YES）；Plücker 关系（UNKNOWN）；混合判别式
   （UNKNOWN）；体积采样（YES）；外幂表示（UNKNOWN）。
6. 两项机械的标准假设：Gram 表示要求 `L>=0`，严格核满足；Plücker
   坐标描述固定秩纯外积，而一般全子集 `L`-ensemble 混合所有阶，最可能
   失败在跨阶统一。

## 0D-5：双曲多项式与自协调障碍

1. 目标范畴：正定锥上的双曲多项式、对数障碍及混合导数。
2. 编码：所有包含概率是行列式主子式，精确事件概率是它们的 Boolean
   Möbius 变换；熵是这些混合导数/系数的对数加权和。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：行列式双曲多项式 Möbius 系数熵的锥内曲率。
5. 原生机械：Gårding 锥（UNKNOWN）；Alexandrov–Fenchel 型不等式
   （NO）；自协调障碍（NO）；混合判别式（UNKNOWN）；容量（NO）。
6. 两项机械的标准假设：Gårding 理论要求沿双曲方向，正定锥满足；
   Möbius 变换保留所需锥序最可能失败。

## 0D-6：代数统计 / 边缘模型

1. 目标范畴：二元随机变量的代数统计模型、边缘多面体和对数线性参数。
2. 编码：`K` 映到满足行列式矩约束的二元联合律；主子式给出所有包含
   矩，Möbius 反演给胞元概率；目标是该半代数模型上参数拉回熵的曲率。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：行列式矩簇上的熵拉回与互信息曲率。
5. 原生机械：矩参数化（YES）；toric ideal（NO）；信息矩阵（UNKNOWN）；
   边缘多面体（UNKNOWN）；半代数消元（NO）。
6. 两项机械的标准假设：矩到胞元的 Möbius 变换为可逆线性变换，成立；
   toric 结构要求单项式参数化，行列式和式最可能失败。

## 0D-7：统计力学 / 子集气体

1. 目标范畴：有限体积格点气体与配分函数。
2. 编码：严格核经 `L` 映到能量
   `E_L(S)=-log det L_S` 的 Gibbs 子集气体；`det(I+L)` 是配分函数，
   DPP 熵是平均能量加对数配分函数。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：行列式多体子集气体在相关矩阵插值下的热力学熵曲率。
5. 原生机械：转移矩阵（YES，路径）；cluster expansion（NO）；
   Griffiths 型不等式（UNKNOWN）；热容恒等式（UNKNOWN）；Lee–Yang 零点
   （NO）。
6. 两项机械的标准假设：cluster expansion 需要可控弱相互作用，最可能
   只在局部区间成立；转移矩阵需要有限范围/有限状态，路径 `L` 满足但
   `K` 仿射中点通常破坏。

## 0D-8：负相关测度与熵泛函

1. 目标范畴：负关联、随机指标集和依赖度量。
2. 编码：每个 `K` 映到一个 DPP 指标向量；块间互信息、总相关和条件熵
   量化其依赖；目标是这些依赖泛函沿核弦的曲率竞争。
3. 忠实性：`EQUIVALENT`。
4. 原生名称：负相关指标族中边缘熵与总相关的弦曲率分解。
5. 原生机械：熵次可加（YES）；Shearer 不等式（UNKNOWN）；负关联
   （YES）；strong data processing（NO）；总相关分解（UNKNOWN）。
6. 两项机械的标准假设：熵次可加对任意有限联合律成立；强数据处理通常
   需要明确通道或收缩系数，当前最可能缺少这样的通道表示。

## 选定桥接种子

- 第一桥接种子：0D-1 信息几何 / 互信息分解。
- 第二桥接种子：0D-2 自由费米高斯态 / 固定基测量熵。

选择只依据二者为 `EQUIVALENT` 且能用目标范畴原生词汇陈述；不表示它们
比其他编码更可能成功。首轮 D10-C 使用第一桥接种子，第二种子保留给后续
独立工作单元，避免同轮混线。
