# D10-M：一般稠密实核 Hessian 探针

这条主实例路线直接在实对称 `K` 的全部坐标上计算全配置 Shannon 熵
Hessian，不使用旧分组交换参数化。对每个精确事件

`p_S(K)=(-1)^|S^c| det(K-I_{S^c})`

及实对称方向 `D`，程序使用

`H''=-sum_S [(p'_S)^2/p_S+p''_S log p_S]`

并将两项分别记录为 Fisher 项和事件加速度项。完整 Hessian 的最大特征
方向随后接受严格可行步长的有限弦检查。

本路线的作用是：

1. 检查正曲率若存在，究竟来自哪一项；
2. 记录最危险方向的矩阵秩、谱和距边界裕量；
3. 为 rank-two 或其他结构化路线提供可复核种子。

所有结果均为 float64 侦察。只有出现远离舍入地板的正信号，才进入有理
冻结和区间认证；有限未命中不证明一般凹性。

核心公式和实现已通过非作者的 n=3、n=5 独立实现及有限差分核验，状态为
`CORRECT`。五批 `n=3..11` 结果共 1662 个中心，未见正曲率。

`dense_hessian.py` 进一步计算 generalized Rayleigh 比值

`rho = acceleration / (-fisher)`。

这个比值不依赖所选的对称矩阵坐标；`rho>1` 才能使总 Hessian 翻正。
`results_round4` 与 `results_round5` 的随机最好值分别为 0.439930 和
0.486479。`optimize_mechanism.py` 保存完整核后作局部定向优化：n=7 达到
0.497233，固定特征向量的 n=11 谱优化达到 0.501403。两个最优机制方向
均为满秩负定方向；所有值仍显著低于 1，只作路线诊断。
