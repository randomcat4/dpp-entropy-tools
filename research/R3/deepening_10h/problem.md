# R3 十小时深化：问题

## 原目标

对有限维实对称严格正收缩核 `0<K<I`，DPP 精确事件律由

`P(A subset Y)=det K[A,A]`

唯一确定。记全子集 Shannon 熵为 `H(K)`。研究是否存在实对称可行弦

`K_- = M-D, K_+ = M+D`

使

`Delta = (H(K_-)+H(K_+))/2-H(M) > 0`。

## 本阶段目标

本阶段不承诺反例存在，接受以下任一可检查进展：

1. 带严格谱裕量、精确事件概率和区间正 gap 的实反例；
2. 严格排除一个自然、非退化且比既有局部四阶引理更大的结构区域；
3. 解决路径稀疏 `L` 精确熵递推与 `K` 空间仿射弦之间的闭包障碍；
4. 导出能改变下一轮搜索参数化的必要条件或互信息机制。

有限未命中不算定理；浮点正号不算反例；漂亮但未核验的恒等式不算完成。
