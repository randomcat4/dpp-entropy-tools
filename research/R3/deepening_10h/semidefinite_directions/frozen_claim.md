# D10-S：半正定方向冻结问题与受限候选

日期：2026-09-08。作者产物，未经独立验缝，不标记 CORRECT。

## G-S：原问题，前提不变

对任意有限 n、实对称 M,D、非空开区间 J，假定对所有 t∈J 都有
0<M+tD<I，且 D≽0 或 D≼0。精确事件律由包含概率 det K_A 的
Boolean Möbius 反演定义，H 为全配置 Shannon 熵，自然对数。
问题：是否对每个 t∈J 都有 H''(M+tD)[D,D]≤0？

边界不在本次范围。非零候选须 rank(D)≥2，且不把从零出发的稀释
包装为新路线。总体状态 INCOMPLETE；下面不是对 G-S 偷加前提。

## S-T：独立列出的可核验子类候选

对任意 n≥2，E={1,2}⊔R，冻结

```
K(t) = [ a+td   b+te   y^T ]
       [ b+te   a+td   y^T ]
       [ y      y      B   ],
D    = [ d e 0; e d 0; 0 0 0 ].
```

B 为任意固定实对称矩阵，y 任意固定实向量；仅要求整个 J 上严格可行。
假设 d≥|e| 或 -d≥|e|。候选结论：

`H''(K(t)) ≤ -4(d²-e²) log 2`。

若 D≠0，则 H''<0（秩一退化单独由仿射事件律证明）；H''=0 当且仅当
D=0。相应任意对称可行弦的 gap 满足
`Delta(t,h) ≤ -2(d²-e²)log(2) h²`。

该子类允许任意 n、任意异质 B 及 y≠0；不是直和构造，但确实要求一对
坐标具有相同外耦合。它是解析闭包前提，不是重启旧重复行数值搜索。
不声称这些前提必要，不声称结论新颖，不声称覆盖一般 PSD 方向。
