# 下一结构轮：人话摘要

这轮没有找到实对称严格反例，但不是空跑。三条完全不同的路线中，两条
留下了可复用、且经非作者验证的结果：

1. **解耦附近不是一个神秘特异点。** 对两块独立核加任意非零的小跨块
   耦合，熵的首个变化是严格向下的四阶项。因此过去约
   `7.11e-15` 的正 gap 应理解为一整片近零带里的舍入翻号，而不是一枚
   孤立的正反例。该结论只覆盖充分小邻域，不是全局凹性定理。
2. **换到路径稀疏 `L` 后，精确熵可以二次时间算。** 选中点集分成若干
   连续段，每段用 continuant，整体用前缀递推；多个小维全事件对照已经
   精确通过。但这种结构不在 `K` 的普通直线取弦下封闭，所以暂时还是
   计算工具，不是反例生成器。
3. **真正不同的三块缺陷族也查了。** 30 个非退化基点、90 条弦全部
   明显为负，没有正候选。这只说明本轮样本不支持继续盲搜，不说明该族
   或一般实核都凹。
