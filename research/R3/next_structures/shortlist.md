# 下一结构短名单

## 1. NS-3：解耦面四阶熵损失

状态：`DEEP / CORRECT`（局部正确性已独立验证；新颖性未审计）。

这是本轮最强的数学结果。它把旧记录中“解耦附近出现约机器精度的正
gap”解释成一个结构性现象：在任意固定非零跨块方向上，熵从解耦点离开
时的首个非零变化是严格负的四阶项。因此需要排除的不是单个坏点，而是
一整片会产生数值近零、但理论上局部向下的邻域。

下一义务：

1. 做外部文献与新颖性审计；在此之前不声称首创。
2. 若要给某个有限 `epsilon` 盖章，补显式可行半径和 `O(epsilon^6)`
   余项界。
3. 将该引理加入搜索过滤器：近解耦微小正 gap 不再进入反例认证队列。

## 2. NS-1：路径稀疏 L 的精确熵递推

状态：`DEEP / CORRECT`（限定在正定三对角路径 `L`）。

这是本轮最强的计算工具。它不靠重复行或置换轨道，而按选中点的连续段
分解精确事件权重，将熵计算从 `2^n` 个事件压到 `O(n^2)` 个区间状态。

下一义务：

1. 解决边缘核 `K` 的仿射弦闭包：找端点和中点都保持路径稀疏 `L` 的
   特殊弦，或发展直接作用于稀疏 `K` 的递推。
2. 在任何严格 gap 声明前加入外向取整的对数区间。
3. 树、箭头和一般低树宽推广继续保持 `HOLD`，直到给出有限消息状态。
