## 本轮新增的作者证明

**NC：非恒定中心弱耦合熵率凹性。** 对实 Wiener 符号 c,g，c 半周期不变且积分 1/2，g 半周期反变且非零。设 a=2||c-1/2||_W<1，b=2||g||_W>0，R=(1-a)/(2b)，rho=(1+a)/2，M=-log(1-rho)-rho。固定奇数 k>=1，gamma=|ghat(k)|²>0，T=min(R/2,2 gamma R³/sqrt(27M))。

在 [-T,T] 上，h(c+tg)+(2/3)gamma²t⁴ 凹。更强的有限结论为：所有 n>=2k，H_n(c+tg)+(2/3)(n-2k)gamma²t⁴ 凹。证明先完成有限 Jensen，再除体积取极限。c 可非恒定，g 可非偶，交叉秩可随体积增长。

核心新桥梁是半填充精确配置密度的 Boolean Fourier 行列式展开与闭步迹展开，给出复参数圆盘上的 |n log2-H_n|<=nM 的解析延拓界。再用负关联匹配控制 t⁴ 首项，Cauchy 估计控制全部高阶项。没有假定高阶系数非负。

固定例 c=1/2+cos(4pi theta)/8、g=cos(2pi theta)/1024 不穿过任何常数符号。证明 h(c+tg)+t⁴/(3*2^43) 在 [-1,1] 凹；不以解耦点为中点的子弦 0,1 有严格下界 h(f_1/2)-(h(f_0)+h(f_1))/2>=7/(3*2^47)。其完整合法区间是 [-384,384]，本稿没有闭合剩余区间。正文另给非偶固定例 g=(cos+sin)/2048，仍认证 [-1,1]。

**NC-channel：通用局部块刷新不可能。** 两个固定严格且非对角的二点 Hermitian 块 A,B，不存在与 C 无关的局部 Markov 矩阵 T_A,T_B，对全部充分小交叉块 C 实现 C->rC (0<r<1)。秩一 C 的约束迫使整个相关部分按 r² 缩放，但满秩 C 的精确四点事件具有非零 r⁴ 项，矛盾。有理例冲突为 3/1048576。它是方法障碍，不是熵凹性反例；不排除 Toeplitz 专用、依赖 C 或非局部通道。
