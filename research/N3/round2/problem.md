# Exact beta-zero slice

The only round-two universal target is B0 in `frozen_theorem_v1.md`:
for every connected strict real symmetric three-point kernel, beta=0
implies det(N)*alpha<=1. The parent global entropy claim is not replaced
by this smaller test. A rigorously reachable zero, a proved restricted
nonvanishing mechanism, or a checkable obstruction to a new sufficient
condition is useful partial progress, but does not prove B0.

The round-one author and review files remain frozen. New mathematics is
confined to this directory. Round-two source baseline is
e476db1bb056af57e883a47f470ea0f4443c1837.
