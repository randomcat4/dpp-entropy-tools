# 冻结命题：三维复合对称中点候选

版本：v1（2026-09-08）

令

```text
K_0 = (a-c)I_3 + c 11^T
```

为实对称严格收缩核，即 `0<K_0<I`。令 `V` 为任意 `3x3` 实对称矩阵，`t>0`，并假设 `K_±=K_0±tV` 也满足 `0<K_±<I`。对由包含概率经 Boolean Möbius 反演得到的完整事件 DPP Shannon 熵记为 `H`。候选命题为

```text
[H(K_-)+H(K_+)]/2-H(K_0) <= 0.
```

若证明，必须覆盖实参数 `c` 的全部允许正负范围与六维任意方向，并单独处理 `c=0`。可利用 `S_3` 对称性把 Hessian 分解为不可约表示，但必须给出每个块的显式符号证书。有限扫描不是证明；若为假，必须给出严格可行反例并经高精度或有理复核。
