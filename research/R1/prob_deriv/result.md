## Formula audited

For a DPP kernel `K` on `[n]`, the verifier uses inclusion probabilities

```text
q_A = P(A subset X) = det K_A
```

and computes full event probabilities only by inclusion-exclusion:

```text
p_S = P(X = S) = sum_{B subset S^c} (-1)^|B| det K_{S union B}.
```

It does not treat principal minors as event probabilities.

For a strictly interior real symmetric positive contraction `K` and real
symmetric direction `V`, the principal-minor derivatives are

```text
d/dt det(K_A+tV_A)|0  = det(K_A) tr(K_A^{-1} V_A),
d2/dt2 det(K_A+tV_A)|0 = det(K_A) (tr(M)^2 - tr(M^2)),
M = K_A^{-1} V_A.
```

The event-probability derivatives `p'_S`, `p''_S` are obtained by applying
the same inclusion-exclusion linear map to these minor derivatives. Entropy
derivatives are then

```text
H'  = - sum_S p'_S (log p_S + 1),
H'' = - sum_S p''_S (log p_S + 1) - sum_S (p'_S)^2 / p_S.
```

## Exact rational probability check

The exact test used the rational `3 x 3` kernel

```text
[[1/3,  1/20, 1/30],
 [1/20, 2/5,  1/25],
 [1/30, 1/25, 1/4 ]]
```

Exact inclusion-exclusion probabilities matched the exact L-ensemble formula
`det(L_S)/det(I+L)` with `L = K(I-K)^{-1}`.

- Sum of event probabilities: `1`.
- Minimum event probability: `11471/360000`.
- Max event-probability denominator: `360000`.
- Minimum principal minor of `K`: `11471/360000`.
- Minimum principal minor of `I-K`: `35551/120000`.

This confirms, on a non-diagonal rational interior example, that the
event-probability layer is not confusing `det K_S` with `P(X=S)`.

## Implementation risks and use in R1

- The analytic determinant derivative path uses `K_A^{-1}`, so it assumes
  strict interior `K`. This is appropriate for R1's interior search, but not
  for boundary certificates.
- Floating positives of `H''` or chord gaps should not be certified from this
  implementation alone. Use it as an independent numeric oracle, then freeze
  candidates and pass exact/rational certification to a separate verifier.
- For larger `n`, inclusion-exclusion is `O(3^n)` if run naively across all
  events and supersets; this child verifier is deliberately bounded to
  `n <= 5` sanity checks.
- The code is suitable as a reference implementation for another agent to
  compare against, but not as a final self-certifier for any candidate
  discovered by the same codebase.
