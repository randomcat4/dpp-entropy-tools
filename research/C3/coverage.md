# Coverage and denominator

- Main preflight: one explicit three-site rational gauge example, all 8
  event identities; one five-site kernel with two diagonal anchors and
  three retention values each. These 6 channel checks are diagnostics.
- Mechanism: one predeclared degree-two complex scalar chord, one n=8
  full-event directional jet, all 256 events and each of three finite
  endpoint/centre entropies. No full Hessian was computed or searched.
- Mechanism exact check: all three-site rational event polynomials for the
  same coefficient construction, a smaller consistency check, not a new
  candidate or an entropy-rate test.
- Independent formula reviewer: two small rational/symbolic gauge examples;
  these are independent reconstructions rather than new search centres.
- True-rate certificate: exactly one fixed candidate, n=4, 3 parameters,
  2 complement choices each, 6 boundary kernels; M=64 and 66 residual rows
  per boundary case; 792 exact complex residual entries; 288 exact event
  determinants. No larger n was run after the sign separated.
- The rate child's own alternate determinant/residual audit is a repeat
  verification of the same object, not new search coverage.
- Radial theorem: two independent nonauthor reviews. Numeric checks never
  stand in for its universal proof; the theorem holds beyond tested matrices.

Resource ceiling was 8 CPU threads / 32 GiB / no GPU. Actual compute commands
used one thread. Process IDs, versions and statuses appear in the saved
outputs. No prior S1 phase scan was rerun, no other research route was taken
over, and no self-waking task was installed.
