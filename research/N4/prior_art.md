# Prior-art scope
The baseline dispatch records Lyons-Steif Conjecture 9.2 (stationary scalar
symbols), Meszaros conditional entropy representations, and Shepp-Olkin
concavity for a sum of independent Bernoulli variables. These do not directly
prove full finite real configuration entropy concavity. Baseline route ledger
provides the checked internal exclusions. N4 does not claim an exhaustive
literature audit or novelty from failure to find a covering theorem.

Targeted live check 2026-09-09: Yuzhou Gu's author-hosted
[Entropy of Determinantal Point Processes](https://sevenkplus.com/data/dpp.pdf),
Theorem 7, proves rank-one-direction concavity because every exact event
probability is affine in that direction. This does not control cross terms
between rank-one directions. The theorem is an inherited exclusion, not an
N4 contribution. The same report distinguishes cardinality entropy from
configuration entropy. No current all-real finite-dimensional resolution was
established by this limited search.
