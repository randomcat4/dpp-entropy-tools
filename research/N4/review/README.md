# N4 independent rational review

This directory contains the independent review path for the 2026-09-09 N4
candidate batch.  It is intentionally narrow:

- reconstruct the full event law from the frozen theorem;
- compute rational directional jets along affine chords in K;
- certify strict endpoint feasibility with exact Sylvester checks;
- use rational logarithm intervals for entropy gaps;
- record input hashes, commands, process ids, source versions, denominators,
  and the rationalization envelope.

The review code does not import candidate search or mechanism scripts.  Pilot
JSON files are used only for the top-level `K`, `D`, and `radius`/`t` data plus
file hashes.
