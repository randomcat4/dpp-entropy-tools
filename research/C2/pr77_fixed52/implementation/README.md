# Independent fixed-object implementation

This code was written by the C2 root from the original mathematical text and final C3 contract. The intended implementation workers remained pending initialization without files and were interrupted. No author checker or PASS output is imported. Manual inspection occurs before the public preparation freeze; no compilation, import, test, pilot or arithmetic occurs before the single production clock.

Phase A independently constructs rational comparison residuals, strict Cstar<C0 difference, operator-bound substitutions, binary negative-entropy derivative constants, uniform and point-specific Bregman/tail constants, and exact geometric sums. Covariance polynomials in u=t/16 are constructed with both Laplace and permutation determinants on the four required site sets; expected coefficients are comparison literals. The finite Fisher projection is algebra only, not a sign claim about response terms.

Phase B uses three independent event constructions. The production route expands permutations through a four-bit frontier. Before processing row i, its bits mark occupied columns i-2,...,i+1; after choosing column i-2+j, the oldest column must be occupied before removal. The sign for a transition is (-1) to the number of already occupied columns strictly to its right. A starting mask3 marks the two nonexistent negative columns; ending mask3 means all actual columns and no future columns were selected. There are six frontier masks with two occupied bits. Each state carries the exact value, first derivative and second derivative in physical t. The first off-diagonal has derivative2, so the second product derivative retains its factor2.

The direct route uses pivoted Bareiss on the literal signed event matrix, checking every division remainder. Through n6 the inclusion route computes principal minors and performs upper-set Mobius inversion without the absent-diagonal helper. Derivatives are independently obtained by replacing one or two determinant rows by their derivative rows, using multilinearity. Values are compared through n8; jets and Mobius values through n6, at every fixed t. A short padded-frontier comparison also checks extraction of leading-block jets before the final row.

Phase C visits every binary word once in a depth19 tree for each t. At depth18, frontier mask3 is exactly the leading18 determinant: any path that selected a future column cannot lose that selected column and finish in mask3. The same tree therefore emits every length18 and19 event without redundant complete enumeration. The absent-count sign is tracked separately from determinant permutation signs. Every emitted N must be positive. Direct event totals and independently accumulated histogram totals must match event_count=2^n, sumN=32^n, sumNprime=sumNsecond=0.

The histogram key is N and each row stores count, sumNprime, sumNsecond, sumNprimeSquared. All are decimal integer strings, sorted by integer N. It is sufficient to reconstruct H=n*log32-sum(count*N*logN)/32^n and Hsecond=-[sum(sumNprimeSquared/N)+sum(sumNsecond*logN)]/32^n. Fisher and acceleration are retained separately. Event-sequence SHA256 covers ASCII lines `word:N:Nprime:Nsecond` in deterministic depth-first order. Histograms and log intervals use gzip JSONL chunks with fixed mtime0 and explicit schema, sizes and hashes.

Phase D uses precision100 Decimal.ln, which is correctly rounded to nearest with ties to even according to the [official Python contract](https://docs.python.org/3/library/decimal.html#decimal.Decimal.ln). Each logarithm is widened by1e-90 using directed subtraction/addition. Exact normalization gives 1<=N<=32^19<10^29. Since exp(3)>13>10, logN<87<100; its nearest-rounding error is at most5e-99. N=1 is exactly0. Subsequent operations use separate FLOOR and CEILING contexts. Signed terms swap endpoints. Decimal negation uses copy_negate to avoid an implicit default-context rounding. No binary float enters a bound.

All finite H, Hsecond, h18 and h18second widths must be at most1e-40. Analytic tails are reported separately. The true Jensen lower bound subtracts E18 only at the midpoint; the point curvature intervals use their distinct Tail18. The first insufficient separation is a terminal unresolved certificate, not a disproof of the underlying mathematical claim. No depth, parameter, precision or budget change follows a failure. General and continuum signs remain outside scope.
