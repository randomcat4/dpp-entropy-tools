# External conditioning dependency check

Scope: the cited probability theorem only, not acceptance of the C3-M1
arithmetic or of a new entropy theorem. Checked directly on 2026-09-09 in
[Lyons–Steif, arXiv v5](https://arxiv.org/pdf/math/0204324).

PDF pp.8–9 define positive contractions on a complex Hilbert space and state
Theorem 2.1 for arbitrary finite exact conditioning. Proposition 2.6 on
p.11 gives the required reverse ordering when observed bits increase.
Thus the reference is not restricted to real kernels or unconditional pair
correlations. Equation (6.5) on p.34 supplies the stationary past-conditional
entropy formula. The proof of Proposition 6.10 on pp.34–35 demonstrates the
extreme-past comparison, and Theorem 6.12 on p.36 identifies the limiting
one-sided process.

For the displayed degree-two C3-M1 symbols, the claimed uniform margin
1/200 supplies positive finite conditioning probabilities. Using finite
conditioning first and then a martingale limit matches the reference's
hypotheses. The separate residual argument, all six boundary approximations,
all event determinants and numerical enclosures still require independent
checking. This reference check neither differentiates an entropy-rate limit
nor converts finite windows into a certificate.
