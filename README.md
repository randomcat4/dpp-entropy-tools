# DPP Entropy Tools

为行列式点过程（DPP）的全子集 Shannon 熵研究制造可复用工具。现已有带独立复核记录的结构定理、有限熵差工具和局部排除结果；一般实对称核的熵凹性仍未解决，没有已认证的实反例。

当前入口（2026-09-09 整合）：

- [成果与证据范围](docs/research_status.md)：历史八路及 S1/N3/N4、C1/C2/C3、W2/W3 的已审结果和剩余问题。
- [路线台账](docs/route_ledger.md)：已证明覆盖的区域、被否定的方法、旧缺口的新状态及开放瓶颈。
- [本次整合记录](docs/integration_20260909.md)：各批 PR 的固定提交、非作者审阅、合并范围和实际服务器复算。
- [未入 PR 产物核对](docs/unpublished_audit_20260909.md)：补回 R1 复现脚本，补记 T3 有限种子复核及整链缺口。

合入 main 表示研究产物已归档并有明确状态，不表示其中每个候选、探索脚本或历史证明均已认证。原始失败版本和冻结文本保留；跨路线的最新状态以以上台账及所链接复核为准。新颖性与论文价值尚未统一审计。

最近的已审结论包括循环平均的完整严格等号条件及 Fourier 模式熵率 gap、常数中心整线凹性及四次定量加强、固定五点框架的近标量全方向负曲率界，以及从安全侧趋近阈值的精确 beta 零点族。W2/C3 的共同刷新基础定理只计一次；一般非常数中心标量弦和一般实核问题仍未解决。

不预设凹性成立或失败。固定标量平稳熵率和实对称反例暂作为工具检验场景，不启动大规模暴力搜索。不使用 math-ultra。

每路一个主 issue 登记范围、一个独立分支开展工作；具体结果通过 Draft PR 审查。主实例常规推进自行决策，只有重要突破或无法自行解决的阻塞才升级。研究正确性、实际执行覆盖、新颖性分别审查。候选冻结后由未参与写作的新上下文验证者审查。

日常协作全部在本库的 issue/PR。历史研究库仅事后记录重大事件和路线变化，不同步日常日志。未公开的历史材料不自动随本库公开；新结果需自包含可复核证据。

起始参考：[Lyons, Determinantal probability: basic properties and conjectures](https://arxiv.org/abs/1406.2707)、[Lyons–Steif](https://arxiv.org/abs/math/0204324)、[Hino–Yano](https://arxiv.org/abs/2404.11024)。各路先核对精确题面与相关定理，引用不构成本库新结果的认证。
